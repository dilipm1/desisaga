Basecamp OAuth Callback

    Next steps (run in your terminal):
    1. Exchange the code for tokens:
      curl -X POST https://launchpad.37signals.com/authorization/token \
        -d "grant_type=authorization_code" \
        -d "code=<CODE_ABOVE>" \
        -d "redirect_uri=http://localhost:3000/oauth-callback.html" \
        -d "client_id=<CLIENT_ID>" \
        -d "client_secret=<CLIENT_SECRET>"
    2. Export the credentials:
      export BASECAMP_ACCOUNT_ID="..."
      export BASECAMP_ACCESS_TOKEN="..."
    3. Preview the sync: npm run sync:basecamp -- --dry-run
